# Demo capture

`demo.gif` is a 12-scene, 28-second animation assembled from screenshots of the running public Streamlit app on October 20, 2026. It shows the built-in dataset; model selection; held-out test metrics and saved-run comparison; PyTorch/Lightning and Optuna controls; preview and configuration of a synthetic 120-row CSV; a simulated numeric drift warning; and a real AI explanation comparing two saved runs. The title strip identifies each step. The GIF is a walkthrough, so each scene is held long enough to read instead of showing a continuous screen recording.

The synthetic CSV was created only for the capture and is not part of the training results table in README. Uploaded rows were not added to the repository or saved in the experiment database.

The live app is at https://efpmqnyhgu7aepxpdqxxi2.streamlit.app/ .
